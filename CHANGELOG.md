# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/). Releases carry a `MAJOR.MINOR.PATCH`
version; while the major version is 0, a minor release may change behaviour.

## [0.2.0] - Unreleased

A test-suite and packaging release. The suite now runs green from a clean checkout in one defined,
reproducible layout, and the repository gains the files a contributor expects.

### Added

- **`scripts/ci_layout.sh`** (tested by `hooks/tests/test_ci_layout.sh`) builds the exact layout the test
  suite expects: a throwaway `$HOME` outside `/tmp`, the checkout extracted from `git archive HEAD` as
  `$HOME/.claude`, a clean virtual environment holding the declared test dependencies, pytest's
  `--basetemp` as a sibling of that home, and `TZ=UTC`. Safety rails make it refuse to act on or inside
  a real `~/.claude`. `--run` executes the full test battery and fails on any red result or on a
  location that ran zero tests.
- **A session guard in `hooks/tests/conftest.py`**: the suite aborts, with a pointer to `ci_layout.sh`,
  when the checkout is not `$HOME/.claude`. Opt-out: `CSA_TESTS_ALLOW_FOREIGN_ROOT=1`.
- **`hooks/run_tests.sh`** now runs four test locations (`hooks/tests`, `tools/gtm/tests`, the shell
  tests, the node test; `ci_layout.sh --run` also runs `live-testing/tests`), stops at the first failure, fails a location that ran zero tests, measures
  coverage only when `pytest-cov` is installed, and no longer needs GNU `timeout`.
- **New tests**: the `Task` dispatcher (`pretooluse_task.py`), `record_model_exception.py`, every
  argparse CLI answering `--help`, the guard-wiring check, the mirror-sync dry run, `ci_layout.sh`, the
  agent-roster generator (`hooks/tests/test_gen_agent_index.py`), the packaging pins
  (`hooks/tests/test_packaging_pins.py`: ruff is pinned to one exact version in `pyproject.toml`,
  `scripts/ci_layout.sh` and `.pre-commit-config.yaml`; the pytest configuration lives in
  `pyproject.toml` with nothing shadowing it; the format-exclude regeneration recipe still works), and a
  check that every agent `repo_manifest.py doctor` inspects has a dossier template.
  `hooks/tests/test_kb_sync_report.py` is the former `scripts/test_kb_sync_report.py`, moved so the suite
  collects it.
- **TODO (fill from the final run):** executed test counts from `bash scripts/ci_layout.sh --run` --
  `hooks/tests`: N, `tools/gtm/tests`: N, node tests passed: N.
- **`scripts/check_guard_wiring.py`**: a fail-closed command-line wrapper around the guard-wiring
  self-check, usable as a CI step (exit 1 on any problem, or if it examined no guard modules).
- **`live-testing/allowlist.example.json` and `live-testing/README.md`**: a self-contained example
  allowlist (localhost and `example.com` hosts only, marked `"_example": true`). The production-mutation
  hook's tests now run against in-file test data, and the tests that pin a real allowlist's policy skip
  with a stated reason when that file is absent or is the example.
- **`knowledge/protected_boards.example.json`**: an example registry for the protected-board gate
  (gate 5b), shipped with an empty `boards` list, so nothing is protected until you list boards.
  `scripts/ci_layout.sh` seeds `knowledge/protected_boards.json` from it when that file is absent.
- **Dossier templates** in `templates/oversight/` for `devops-architect`, `observability-architect` and
  `video-producer`. Without them `repo_manifest.py doctor` could never reach zero findings on a fresh
  repository.
- **`hooks/runtime_mirror_sync.py --dry-run [--config PATH]`** exports, redacts and checks into a
  temporary directory and reports what it found, publishing nothing. `--config` is accepted only with
  `--dry-run`.
- **Packaging and lint configuration**: `pyproject.toml` (project metadata; not an installable package;
  `test` and `lint` extras; ruff and pytest settings; ruff pinned to 0.15.18), `.editorconfig`, and
  `.pre-commit-config.yaml` for contributors' own clones.
- **Documentation**: `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1),
  this changelog, `ARCHITECTURE.md`, `GLOSSARY.md`, a documentation index (`docs/README.md`), and the
  agent roster `docs/agents/README.md`, generated by `scripts/gen_agent_index.py` from the agent
  frontmatter, the model pins in `knowledge/model_policy.json` and the new `knowledge/agent_meta.json`
  (the generator fails when the three disagree).

### Changed

- **The test suite no longer reads the machine it runs on.** The settings-wiring test reads the
  checkout's `settings.json`; tests that needed a live allowlist, `launchctl`, installed job plists, a
  per-machine ledger or an optional private telemetry parser now use sandboxed data or skip with a
  stated reason; the telemetry degrade-path tests run when that parser is absent; the workflow
  model-gate test sets `CSA_ENFORCE=1` itself instead of relying on a global enforcement marker; the
  `.gitignore` protection tests detect the allow-list model and skip on a conventional ignore file; the
  node triage test no longer depends on a commit absent from this history.
- **Scripts take repository roots from `knowledge/repo_registry.json`** instead of a default product
  path: `scripts/disk_janitor.sh` (which also refuses an unusable `HOME`) and
  `schedules/run_oversight_job.sh` (browser-pool priming). The shell gates (`hooks/bash_gate.sh`,
  `hooks/post_bash_gate.sh`, `hooks/agent_router_path.sh`) are `shellcheck -S warning` clean, and the
  set of commands `bash_gate.sh` matches is pinned by a table test.
- **Lint**: every finding of ruff's default rule set (`E4`, `E7`, `E9`, `F`) was fixed at its cause,
  without autofix, and `ruff check .` is clean.
- **`pytest.ini` is replaced** by `[tool.pytest.ini_options]` in `pyproject.toml`.
- **README rewritten** for a first-time reader: what the runtime is, its three original ideas, what
  each gate blocks, a repo map, the agent roster summary and honest caveats. The token-cost figure is
  now stated as a rough list-price estimate ("on the order of tens of thousands of dollars") in
  README, `POSTMORTEM.md` and `CLAUDE.md`.
- **`settings.json` template trimmed to the runtime's own wiring**: it now also wires the `Workflow`
  model gate, the Playwright mutation guard (`block_prod_mutations.py`), the disk-pressure check and
  the Bash failure path; personal preferences (voice cues, theme, status line, plugins, effort level)
  and the Keychain-reading auto-allow are gone. The model/effort drift guard and the agent router
  and obligations hooks are opt-in, not wired. Four token-printing commands (`gh auth token`,
  `gcloud auth print-access-token`, `gcloud auth application-default print-access-token`,
  `gcloud secrets versions access`) are denied; the two Drive- and Gmail-specific deny entries are gone.

### Fixed

- The `settings.json` template wired the deleted `hooks/no_artifact.py`, which blocked every
  Artifact tool call; that hook is no longer wired.
- `hooks/cycle_budget.py --help` crashed on Python 3.14: an unescaped `%` in an argparse help string.
- `hooks/record_review.py` in log-only mode printed "recorded" although it wrote nothing. It now says
  `NOT recorded`, names the switch that turns enforcement on, and exits non-zero.
- `scripts/lane.sh` now links `node_modules` from the main checkout up to five directory levels deep
  (it searched shallower and missed packages installed in nested sub-projects, so a lane's checks
  failed there). The search skips `.git` and `.claude/worktrees`, does not descend into a `node_modules`
  it has found, and keeps searching elsewhere; tests in `hooks/tests/test_lane_sh.py` pin the depth and the skips.

### Removed

- `scripts/legacy/` (superseded shell guards and their tests) leaves the public export; it remains in
  the author's runtime.
- `pytest.ini` (see Changed) and `scripts/test_kb_sync_report.py` (see Added).

### Known gaps

- **Next refresh, not this release.** The GitHub Actions workflow and the issue and pull-request
  templates (`.github/`), the hooks-only installer `scripts/install_hooks.sh`, and the `demo/`
  walkthrough. Until the workflow exists, run the checks in [`CONTRIBUTING.md`](CONTRIBUTING.md) locally.
- **Files excluded from lint** until the in-flight change that holds each one lands
  (`[tool.ruff] extend-exclude` in `pyproject.toml`; each is removed from that list when its change
  lands):
  - `hooks/tests/test_repo_manifest.py`
  - `hooks/tests/test_codex_canary.py`
  - `hooks/tests/test_codex_review.py`
  - `scripts/repo_manifest.py`
  - `scripts/legacy/` (runtime-only, see below)

  `shellcheck` skips `scripts/codex_review.sh` for the same reason. The held change also carries the
  last hermeticity fixes for `hooks/tests/test_codex_review.py`: a skip for the check that needs a
  per-machine consent marker, and resolving its copy source without `$HOME`.
- **Formatting is deferred.** `ruff format --check` passes only because the files a one-time formatting
  pass would change are listed in `[tool.ruff.format] exclude`. One dedicated formatting commit will
  empty that list.
- **Ruff runs its default rule set only.** A wider set (import order, bugbear, pyupgrade, line length)
  is a planned, measured follow-up.
- **`scripts/legacy/` is runtime-only.** `hooks/wheel_launch_context.py` still names one script from it
  (`scripts/legacy/get_test_secret.sh`) in a deny rule for a launched session, so that rule names a script
  this repository does not ship.
- **Turn enforcement on only after creating `allowlist.json`.** Nothing seeds
  `live-testing/allowlist.json` yet (the hooks-only installer that will is in the next refresh). With
  enforcement on and no such file, the Playwright guard (`hooks/block_prod_mutations.py`) has no policy to
  match: it denies every interaction (click, type, form fill, `browser_evaluate`), while plain navigation
  and snapshots still pass. Copy the example first:
  `cp live-testing/allowlist.example.json live-testing/allowlist.json`.
- **Gates 1, 2, 3, 3b, 3c and 4 do not look inside `bash -c`, `sh -c` or `eval` strings.** `git stash` and
  `git add -A` are blocked as plain commands but not when wrapped, for example `bash -c 'git stash'`. A
  wrapped `git commit` also skips the pathspec check, the review gate and the commit claims, because those
  gates only run on a command they can see is a commit. Gate 1b catches a wrapped redirect over a
  historical blob except inside single quotes (`'…'` or `$'…'`, which it treats as literal), and gate 1c
  re-parses nested strings, but only for `gcloud`. Gate 5 (`gh issue close`) does not look inside either.
  Closing this is a separate, security-reviewed change to the tokenizer.
- **Gate-side fail-open `xfail`s.** `hooks/tests/test_pretooluse_task.py` carries `xfail(strict=True)`
  cases for an empty or unparseable `Task` payload: `hooks/model_pin_gate.py` documents that such a
  payload is allowed (fail-open) but denies it with `pin-inherit-drift` under enforcement. The gate fix
  is a separate, security-reviewed change; the markers come off when it lands.

## [0.1.1] - 2026-10-10

The October update.

### Added

- Plain-English explainers for four more agents (`devops-architect`, `observability-architect`,
  `session-coordinator`, `video-producer`), and `docs/patterns/estimate-feedback-loop.md`, a write-up of
  a domain-team pattern whose agents are not published.
- `scripts/kb_sync_report.py` and its test.

### Changed

- `hooks/block_prod_mutations.py` and its tests: a scoped, allowlist-driven way to permit interaction
  on an otherwise read-only production host.
- The `lane-start` and `lane-cleanup` skills were reworked; the `browser-ops`, `code-reviewer` and
  `plan-reviewer` agent definitions, the GTM, oversight and skills subsystem docs, and
  `knowledge/model_policy.json` were updated; `README.md` and `POSTMORTEM.md` were refreshed.

## [0.1.0] - 2026-10-02

First public release: the runtime as an exported, redacted bundle.

### Added

- The git gate chain: a numbered `PreToolUse:Bash` dispatcher (`hooks/pretooluse_bash.py`) whose gates
  block destructive git state changes, bulk staging, commits without an explicit pathspec, commits whose
  exact content has no recorded review, contested file claims, and fabricated issue closes.
- The `PreToolUse:Task` dispatcher (`hooks/pretooluse_task.py`): a model-pin gate and a fan-out pacer
  for sub-agent dispatch.
- Agent definitions (`agents/`): the dev-workflow roster, the oversight roster, and the GTM and venture
  departments, each with a plain-English explainer under `docs/agents/`.
- Subsystem reference docs (`docs/subsystems/`), saved workflow scripts (`workflows/`), the
  scheduled-job wrapper and templates (`schedules/`, `templates/`), and a spend-ledger schema and pricing
  table (`telemetry/`).
- `OPERATING_CONTRACT.md`, `POSTMORTEM.md`, `SUPPORT.md` and the MIT `LICENSE`.
