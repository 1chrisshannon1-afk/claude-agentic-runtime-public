# B2B Software Video Types Catalog

Terse, applicable rules per video type for a worker agent producing B2B software marketing/product
video. Hard constraints below (operator rulings) override anything conflicting in cited sources.

**Provenance:** aggregated from third-party creator-tool, vendor, and practitioner guides unless a source is marked OFFICIAL (published by the platform, standards body, regulator, or licensor itself). Every non-OFFICIAL source in this file is practitioner opinion, not platform documentation; any platform-behaviour claim (a platform limit, cap, spec, ranking behaviour, or policy) that rests only on such a source is UNCONFIRMED-PRIMARY (the `INDEX.md` flag set) until a platform page confirms it — never report it as the platform's own rule.

**Hard constraints (never contradict, all types):**
- B-roll ≤2.5s per shot, ≤20% of runtime, never two consecutive shots, none starting before 3.0s.
- Product-first opens — show the real product before anything else.
- Vocabulary and claims are per company, not universal: banned terms, numeric-claim restrictions,
  and any other wording rule: follow the company pack's `claims_policy` and that company's own
  video-producer dossier; where neither states them, DEGRADED — never invent, assume, or carry over another company's list
  (see `INDEX.md`'s precedence note).
- Viewing review: the rendered cut is watched — contact sheets against the timed transcript, per shot (primer §4/§7) — before any upload; the seat's own frame-viewing review satisfies this, no separate human viewer is required.

## 1. Intro / Brand Intro Video

- **Purpose:** first impression — who you are, who it's for, why it exists; not a feature list.
- **Length:** 60–90s (homepage/YouTube channel trailer); 15–30s cutdown for paid/social.
- **Platform fit:** homepage hero, YouTube channel trailer, LinkedIn company page pinned post.
- **Structure beats:** problem/context (lead with the problem, not the product per founder-video
  norms) → who this is for → product-first visual proof → one-line differentiation → CTA.
- **CTA:** "See it in action" / "Start free" / link to demo or signup — one CTA only.
- **Thumbnail/title:** company name + one plain-language outcome; face-forward if founder-led;
  avoid jargon in title (title should never repeat the thumbnail's hook, per YouTube CTR practice).
- **Success metric:** watch-through rate to :30, click-through to next page/demo.

## 2. Explainer Video

- **Purpose:** clarify positioning/value prop fast; reduce "what does this even do" confusion.
- **Length:** 60–90s standard; 15–30s cutdown for hero/paid placements.
- **Platform fit:** landing page hero, homepage, pre-demo email, paid social awareness.
- **Structure beats:** hook (pain point in first 3s) → before-state → how it works (product-first,
  plain language) → transformation/outcome → CTA.
- **CTA:** "Get started" / "Book a demo" — single, visually obvious.
- **Thumbnail/title:** plain-language value statement, no internal jargon; avoid vague titles like
  "Introducing X" alone — pair with the outcome ("How X helps you do Y").
- **Success metric:** completion rate, click-through to signup/demo page.

## 3. Feature Demo Video

- **Purpose:** show one feature/workflow working, for evaluation-stage buyers or in-app discovery.
- **Length:** 60–90s per feature; homepage/product-page demos should not exceed 90s (completion
  drops sharply past 60s); a full late-stage/technical demo can run 2–5 min for engaged viewers.
- **Platform fit:** product page, in-app feature announcement, sales enablement (dropped in chat
  during a deal), YouTube.
- **Structure beats:** name the workflow/outcome up front → real product screen walkthrough (no
  invented UI) → the specific result the user gets → CTA back to the product or next feature.
- **CTA:** "Try this feature" / in-app deep link / "See full demo."
- **Thumbnail/title:** name the concrete task the feature does ("Assign a job in two clicks"), not
  the feature's internal name.
- **Success metric:** feature adoption after view, in-app click-through, sales-cycle influence.

## 4. Tutorial / How-To Video

- **Purpose:** answer a question the user ALREADY knows they have ("how do I do X").
- **Length:** 60–120s per task; keep one task per video rather than a long multi-task video.
- **Platform fit:** help center, in-app help widget, YouTube (searchable), support ticket replies.
- **Structure beats:** state the task → numbered steps on real screens → confirm the result →
  small CTA to the next related task (tutorials chain into each other; onboarding videos do not).
- **CTA:** "Next: do Y" or link to next tutorial in the sequence.
- **Thumbnail/title:** literal task phrasing matching how a user would search ("How to export a
  report as a PDF") — optimize for on-platform search, not curiosity.
- **Success metric:** support-ticket deflection, task completion rate, search impressions.

## 5. Onboarding Video

- **Purpose:** orient a brand-new user — answers questions the user doesn't yet know to ask.
  Different job from a tutorial: every step must be named BEFORE it happens, not explained after.
- **Length:** 60–90s total, or 3–5 short steps at ~15–20s each if segmented per step.
- **Platform fit:** in-app first-run experience, welcome email, product-led-growth signup flow.
- **Structure beats:** start with the outcome the user will reach → 3–5 concrete steps on real
  screens → end on the user successfully at the next milestone → CTA to the next action in-app.
- **CTA:** "Do this next" (in-app deep link), not an external link — keep the user in-product.
- **Thumbnail/title:** rarely has its own external thumbnail (usually embedded/auto-played in
  product); if surfaced externally, title as "Get started with X" — where the company's claims list
  forbids numeric time claims, use qualitative framing ("in a few minutes") rather than an exact
  figure.
- **Success metric:** activation rate, time-to-first-value, day-1/day-7 retention.

## 6. Release Notes / Changelog Video

- **Purpose:** show what changed and why it matters; drives re-engagement and feature adoption.
- **Length:** 30–60s per release; reserve video for releases that are visually demonstrable or
  materially change a workflow — lead with text/written notes for API changes and bug fixes.
- **Platform fit:** in-app release widget, changelog page (embedded at top), email digest, X/social
  clip, YouTube (cadence: roughly every 2–4 weeks is sustainable, not every release).
- **Structure beats:** name the change → show it on real screens (before/after if useful) → state
  the concrete benefit → link to full written changelog for detail.
- **CTA:** "Try it now" (in-app link) or "Read full release notes."
- **Thumbnail/title:** version/date + one plain benefit phrase ("Faster job scheduling — Sept
  update"); avoid internal codenames.
- **Success metric:** feature adoption lift post-release, changelog page engagement.

## 7. FAQ / Objection-Handling Video

- **Purpose:** answer one specific buyer concern (price, complexity, trust, switching risk) — not
  a general FAQ dump. Each major objection gets its own short video.
- **Length:** 60–90s per objection.
- **Platform fit:** sales follow-up email/video message, pricing page, retargeting ad, chat widget.
- **Structure beats:** state the objection plainly (don't dodge it) → direct answer with proof
  (real numbers/screens where allowed, no time/accuracy claims) → reframe the value → soft CTA.
- **CTA:** "Talk to us" / "See pricing" / "Book a call" — low-friction, not a hard sell.
- **Thumbnail/title:** phrase as the buyer's own question ("Is this hard to set up?").
- **Success metric:** objection-specific conversion lift, sales-cycle time reduction.

## 8. Comparison Video

- **Purpose:** address "why you vs. alternative" at the evaluation stage; fact-based, not a dunk.
- **Length:** 60–120s.
- **Platform fit:** comparison landing page, sales enablement (dropped in chat when a competitor's
  name surfaces), retargeting ad.
- **Structure beats:** name the category/decision the buyer faces → objective criteria comparison
  (real product screens, not caricature) → where you differentiate → optional customer-who-switched
  proof point → CTA.
- **CTA:** "See the full comparison" / "Book a demo."
- **Thumbnail/title:** "[Category] vs. [Category]" or "X alternative" phrasing (search-friendly);
  never name a specific competitor disparagingly.
- **Success metric:** comparison-page conversion rate, competitive win rate.

## 9. Testimonial Video

- **Purpose:** short, unstructured customer statement of satisfaction — emotional trust-building,
  top-of-funnel/mid-funnel credibility. Not a structured narrative (that's a case study, below).
- **Length:** 60–120s.
- **Platform fit:** homepage, pricing page, LinkedIn, sales enablement clips.
- **Structure beats:** who they are/role → what problem they had → one clear win in their words →
  would-recommend statement. Real customer, real voice — unscripted outperforms scripted.
- **CTA:** "See more stories" / "Get started" (soft, placed after the testimonial, not during).
- **Thumbnail/title:** customer's name/company + role; face of the customer, not the product.
- **Success metric:** page-level conversion lift where embedded, sales-deck usage frequency.

## 10. Case Study Video

- **Purpose:** structured proof — problem, decision process, measurable outcome. Carries more
  weight late-stage than a testimonial because it gives evidence a buyer can justify internally.
- **Length:** under 90s for cold/top-of-funnel outreach; 2–3 min for mid-funnel evaluation sends;
  3–5 min for technical/in-depth use-case videos to already-interested technical buyers.
- **Platform fit:** sales enablement, mid-funnel email nurture, resource/customer-stories page.
- **Structure beats:** customer's starting situation and stakes → why they chose you → decision
  process → implementation → measurable outcome (real, sourced numbers only — never fabricated) →
  CTA to a similar use case.
- **CTA:** "See if this fits your business" / "Book a demo" / "Read the full case study."
- **Thumbnail/title:** customer company name + outcome framed qualitatively ("How [Company]
  streamlined job scheduling") — never an invented number, and no number at all where the
  company's claims list forbids it.
- **Success metric:** sales-cycle influence (deals citing the case study), mid-funnel conversion.

## 11. Founder Update / Investor Update Video

- **Purpose:** build trust through founder authenticity; for investor updates, credibility over
  polish — a clear screen recording from a founder who knows the customer beats a glossy ad.
- **Length:** 60–120s; keep founder-to-camera videos under 2 minutes.
- **Platform fit:** LinkedIn, investor update email/deck, company blog, internal all-hands.
- **Structure beats:** lead with the problem/struggle (not the product) → what changed/shipped →
  why it matters to the customer or business → what's next. For investor cuts: emphasize unit
  economics and traction over feature detail as the company matures.
- **CTA:** "Follow for updates" (public) or none (investor-only distribution).
- **Thumbnail/title:** founder's face, plain statement of the update's subject; avoid hype words.
- **Success metric:** engagement rate (public), investor read/response rate (private).

## 12. Webinar Cut-Down Video

- **Purpose:** repurpose a longer live session into scannable, purposeful segments — never post
  the raw recording as the primary asset.
- **Length:** 30–60s clips for social/awareness; 3–5 min highlight reel for a broader recap;
  publish within 24–48 hours of the live session while it's still topical.
- **Platform fit:** LinkedIn/X clips, YouTube Shorts (short cuts), YouTube/resource page (highlight
  reel), email follow-up to registrants.
- **Structure beats:** pull one self-contained moment (a tip, a stat, a memorable quote) per clip →
  add captions (silent viewing is the norm on social) → end each clip with a pointer to the full
  session.
- **CTA:** "Watch the full session" / "Register for the next one."
- **Thumbnail/title:** the specific insight/quote, not "Webinar Recap" generically.
- **Success metric:** clip view-through rate, full-session watch-through from clip referral.

## 13. Event Video (Conference / Trade Show)

- **Purpose:** capture presence, credibility, and real product-in-use moments from an event.
- **Length:** 60–90s recap; 15–30s teaser/story cuts during the event.
- **Platform fit:** LinkedIn, Instagram/Facebook Stories (during event), YouTube (post-event recap).
- **Structure beats:** on-site product-first moment → attendee/customer interaction → key takeaway
  or announcement made at the event → CTA.
- **CTA:** "See what we showed" / link to a related demo or landing page.
- **Thumbnail/title:** event name + company; a real photo/frame from the event, not stock imagery.
- **Success metric:** engagement rate, booth/meeting follow-up conversion.

## 14. Recruiting / Employer Brand Video

- **Purpose:** humanize the company for candidates; day-in-the-life and employee-testimonial
  formats outperform scripted corporate reels — candidates can tell when a line is read verbatim.
- **Length:** 60–90s for employer-brand/testimonial cuts; 2–3 min for day-in-the-life content;
  keep any single video under 3 minutes (drop-off is steep past that).
- **Platform fit:** careers page, LinkedIn, job posting embeds, Indeed/Glassdoor profile.
- **Structure beats:** real employee (not an actor) → what they actually do day-to-day → why they
  stayed/joined → culture/benefit specifics → invitation to apply.
- **CTA:** "See open roles" / "Apply now."
- **Thumbnail/title:** employee's face + role title, plain language, no corporate-speak.
- **Success metric:** application rate from video-referred traffic, careers-page time-on-page.

## 15. Ad Creative Video (Paid Social/Search)

- **Purpose:** drive awareness or direct response at top-of-funnel; must earn attention in the
  first 3 seconds before any skip/scroll.
- **Length:** 15–30s for awareness; under 90s for direct-response/YouTube in-feed (recommended
  even though platforms allow far longer).
- **Platform fit:** LinkedIn (16:9, 1:1, 4:5, 9:16 all supported; MP4/H.264, ≤200MB, 30fps),
  YouTube in-feed (16:9 standard, keep under 90s), TikTok/Reels/Shorts (9:16 vertical, mobile-first).
- **Structure beats:** hook in first 3s (respecting the b-roll timing constraint — no b-roll shot
  before 3.0s) → product-first proof, not abstract concept → single value point → CTA overlay
  (assume sound-off viewing; caption everything).
- **CTA:** on-screen button/overlay text, not narration-only — many viewers watch muted.
- **Thumbnail/title:** platform auto-generates a frame in-feed; for YouTube in-feed ads, pick a
  clear product-visible frame as the static preview.
- **Success metric:** click-through rate, cost-per-click/-lead, view-through rate at 3s/25%/50%.

## 16. Teaser Video

- **Purpose:** build anticipation for an upcoming launch/feature/event without revealing everything.
- **Length:** 15–30s.
- **Platform fit:** LinkedIn, Instagram Stories, X, YouTube Shorts, email pre-announcement.
- **Structure beats:** glimpse of the real product (product-first still applies — no abstract
  animation standing in for the product) → open question or "coming soon" framing → date/CTA to
  follow for the reveal.
- **CTA:** "Follow for the reveal" / "Get notified."
- **Thumbnail/title:** intentionally partial reveal; avoid overpromising specifics not yet shipped.
- **Success metric:** follow/subscribe lift, reveal-day launch video view rate.

## 17. Shorts / Vertical Micro-Content

- **Purpose:** top-of-funnel discovery; a teaser that pulls viewers toward longer cornerstone
  content — treat as a discovery channel, not a standalone sales tool.
- **Length:** 15–60s (30–60s is the most commonly cited effective range); vertical 9:16, 1080×1920.
- **Platform fit:** YouTube Shorts, Instagram Reels, TikTok, LinkedIn's vertical short-form feed
  (live in 2026).
- **Structure beats:** immediate hook (no slow build — first 1–2s decide the scroll) → one single
  idea or moment (not a compressed long-form video) → caption-forward (assume muted autoplay) →
  soft pointer to full content.
- **CTA:** "Full video linked" / profile link — never assume a click mid-scroll.
- **Thumbnail/title:** first-frame IS the thumbnail on most vertical feeds — treat frame 1 as the
  thumbnail design surface; keep on-screen text under ~4 words per beat.
- **Success metric:** completion/loop rate, follower growth, click-through to full-length content.

## Cross-Cutting Rules (apply to every type above)

- **Platform aspect ratios (2026):** 16:9 (1920×1080) for YouTube long-form/website embeds; 9:16
  (1080×1920) for Shorts/Reels/TikTok/Stories/LinkedIn vertical feed; 1:1 or 4:5 (1080×1350) for
  LinkedIn/Instagram main feed. Export per-ratio with reframed subjects, not one careless center-crop.
- **File specs (paid/social):** MP4, H.264, 30fps baseline; LinkedIn caps at 200MB.
- **Captions:** burn in or provide captions on every social/ad cut — assume muted/silent viewing.
- **Thumbnail/title as one unit:** thumbnail opens a curiosity gap; title gives context and never
  repeats the thumbnail's hook. Faces with clear expression beat text/product-only thumbnails.
  Keep thumbnail text to ≤4 words.
- **B2B CTR reality:** ~3.5–5% is normal for B2B YouTube content — a structural feature of a
  selective professional audience, not a failure signal on its own.
- **Vocabulary and claims (every type):** apply the company's own list (pack `claims_policy`, else
  dossier, else DEGRADED) to narration and on-screen copy, regardless of what a source or sales
  narrative suggests — plain outcome language by default.
- **B-roll discipline:** every shot ≤2.5s, ≤20% of total runtime, never two consecutive, none
  starting before 3.0s.
- **Product-first open:** the first substantive visual is the real product, never stock/abstract/
  generic office b-roll.
- **Mandatory viewing review:** every finished cut is watched in full before it is ever uploaded.
